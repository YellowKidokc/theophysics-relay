## The Process (per folder)

### Step 1: Intro (the reading AI)
- List the folder contents (depth 2)
- Read enough of each file to understand what it is (first 20-30 lines)
- Write a SHORT verdict: what's here, which bin, why
- Post the verdict for the other AI to see

### Step 2: Agreement (the other AI)
- Read the verdict
- Confirm OR object with a specific reason
- If both agree → move to Step 3
- If disagreement → discuss once, then decide. If still stuck → bin = REVIEW

### Step 3: Script (whichever AI didn't do Step 1)
- Write a Python script named `_SORT_[foldername].py` 
- The script does ONE thing: moves files to their agreed bins
- Script goes IN the folder it sorts (so David can inspect before running)
- Script must be **dry-run by default** — prints what it WOULD do
- Pass `--execute` flag to actually move files

### Step 4: Next folder
- Alternate roles: if AI-A did the intro on folder 1, AI-B does intro on folder 2
- Keep going until every folder in `.ZZZ_LEGACY_FOLDERS` is covered

### Step 5: Aggregate
- After all folders are done, write `_SORT_ALL.py` in `.ZZZ_LEGACY_FOLDERS\`
- This master script calls every individual sort script with `--execute`
- David runs ONE script and everything moves

---

## Rules

1. **No AI moves files directly.** Scripts only. David executes. (Rule 0)
2. **No duplicates.** If the file already exists at the destination, the script logs it and skips.
3. **No deletes without the DELETE bin.** Even then, the script moves to a `_TRASH\` staging folder first, not actual deletion.
4. **Preserve folder structure.** When moving to B_SERIES or OBSIDIAN, keep the folder name intact unless it conflicts.
5. **Every script is portable.** Works from any location after a GitHub download. Paths are variables at the top of the file.
6. **David can stop at any time.** If he overrides a bin decision, update the script.
7. **No approval needed from David for OBSIDIAN/B_SERIES/DELETE decisions** — both AIs agree and that's the decision. David will catch anything wrong.

## Script Template

```python
"""
_SORT_[foldername].py
Generated by: [AI name]
Agreed by: [other AI name]
Date: YYYY-MM-DD

Sorts contents of [foldername] into bins.
Dry-run by default. Pass --execute to move files.
"""
import os
import shutil
import sys

DRY_RUN = "--execute" not in sys.argv

# === CONFIGURATION ===
SOURCE = r"C:\Users\David\Documents\faiththruphysics.com\.ZZZ_LEGACY_FOLDERS\[foldername]"
OBSIDIAN = r"\\192.168.2.50\h_hp\Obsidian"
B_SERIES = r"C:\Users\David\Documents\faiththruphysics.com\B_series"
TRASH = r"C:\Users\David\Documents\faiththruphysics.com\.ZZZ_LEGACY_FOLDERS\_TRASH"

# === MOVES ===
# Format: (source_path, destination_path, bin_name)
MOVES = [
    # Example:
    # (os.path.join(SOURCE, "somefile.md"), os.path.join(B_SERIES, "somefile.md"), "B_SERIES"),
]

def execute():
    for src, dst, bin_name in MOVES:
        if DRY_RUN:
            print(f"[DRY RUN] [{bin_name}] {src} -> {dst}")
        else:
            os.makedirs(os.path.dirname(dst), exist_ok=True)
            if os.path.exists(dst):
                print(f"[SKIP] Already exists: {dst}")
                continue
            shutil.move(src, dst)
            print(f"[MOVED] [{bin_name}] {src} -> {dst}")

if __name__ == "__main__":
    if DRY_RUN:
        print("=== DRY RUN (pass --execute to move files) ===\n")
    execute()
    if DRY_RUN:
        print(f"\n=== {len(MOVES)} moves queued. Run with --execute to apply. ===")
```
